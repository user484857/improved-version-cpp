About This Data

What is measured vs estimated, data sources

Measured (Real Sensors)

  • Color Sensor Value

    Read from iColorSensor_SL at the Sorting Line station. Integer value 0-300.

  • Quality Grade (A/B/C)

    Derived directly from color sensor ranges: A = 250-300, B = 130-190, C = 40-60.

  • Chamber Burn Time

    Duration between bLamp_MS = True and bLamp_MS = False. Timed from actuator events.

  • Run Count / Timestamps

    Each run starts when bMotor_HBW_StackerCrane_torack fires. Timestamps from CSV event log.

Not Available

  • Temperature

    No temperature sensor on the Fischertechnik oven. Any temperature shown elsewhere uses Newton's heating law model (estimated).

  • Capacity / Throughput Limit

    Theoretical max throughput is calculated from ideal cycle times, not from actual machine capacity specifications.

  • Failure Causes

    The system has no failure detection. Grade C is not a "failure" - it is a valid sorting outcome based on workpiece color.
