Data Transparency

What is measured vs estimated — data sources and limitations

Measured (Real Sensors)

  • Color Sensor Value

    Read from iColorSensor_SL at Sorting Line. Integer 0-300.

  • Quality Grade (A/B/C)

    Derived from color sensor: A = 250-300 (white), B = 130-190 (red), C = 40-60 (blue).

  • Chamber Burn Time

    Duration between bLamp_MS = True and bLamp_MS = False.

Not Available

  • Temperature

    No temperature sensor. Any temp values are estimated via Newton's heating law.

  • Failure Causes

    No failure detection. Grade C is a valid sort outcome, not a defect.
